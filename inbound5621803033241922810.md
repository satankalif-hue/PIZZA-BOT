# Pizza-bot (Toskania)

Pracownik pisze na Messengerze -> bot potwierdza (Tak/Popraw) -> zamówienie wskakuje do panelu
-> odhaczasz -> bot pisze "Twoja pizza jest gotowa".

## 1. Uruchom lokalnie (test parsera i panelu)
    npm install
    PANEL_KEY=test node server.js
    # panel: http://localhost:3000/?key=test

## 2. Hosting (Render.com, darmowy plan)
1. Wrzuć folder na GitHub (bez .env).
2. Render -> New Web Service -> repo. Build: `npm install`, Start: `npm start`.
3. W Environment dodaj zmienne z `.env.example`.
4. Adres typu https://twoja-nazwa.onrender.com to Twój serwer.
   Panel otwierasz jako https://twoja-nazwa.onrender.com/?key=TWOJE_HASLO
   i dodajesz do ekranu głównego telefonu.

Uwaga: darmowy plan Rendera usypia serwer po ~15 min bez ruchu i kasuje plik zamówień
przy restarcie. Pierwsza wiadomość po przerwie może dojść z opóźnieniem. Na start to wystarczy;
potem można dopiąć Supabase albo płatny plan.

## 3. Meta for Developers (Messenger)
1. Strona pizzerii na Facebooku (musi istnieć).
2. developers.facebook.com -> Moje aplikacje -> Utwórz aplikację -> typ "Biznes" -> dodaj produkt "Messenger".
3. Messenger -> Ustawienia API -> Połącz stronę -> wygeneruj token -> wpisz jako PAGE_TOKEN.
4. Ustawienia aplikacji -> Podstawowe -> Klucz tajny -> APP_SECRET.
5. Messenger -> Webhooki: URL zwrotny = https://twoja-nazwa.onrender.com/webhook,
   token weryfikacyjny = VERIFY_TOKEN. Zaznacz pola: messages, messaging_postbacks.
6. Aplikacja w trybie deweloperskim: dodaj pracowników w Role -> Testerzy (każdy musi zaakceptować
   zaproszenie). Tylko oni mogą pisać do bota, bez weryfikacji Mety.

## Komendy pracownika
- "diavola na 15:30", "serowa asap", "palermo bez cebuli", "coś z szynką i pieczarkami"
- "menu" - lista pizz, "anuluj" - odwołanie ostatniego zamówienia
